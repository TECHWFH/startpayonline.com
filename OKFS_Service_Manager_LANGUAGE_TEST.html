📋 Services की सूची

GitHub पर कैसे अपडेट करें?

1. ऊपर से Updated services.json डाउनलोड करें।
2. OKFS Branch की services.json खोलें।
3. GitHub में Upload files से इसी नाम की फाइल Replace करें, या फाइल खोलकर Edit में डाउनलोड की हुई JSON सामग्री Paste करें।
4. Commit changes करें। Deployment के बाद नई Service वेबसाइट पर दिखेगी।

यह Manager केवल आपके Browser में Data Edit करता है। GitHub पर सीधे Save नहीं करता। GitHub Password या Token यहाँ न डालें। Delete करने पर फाइल डाउनलोड/Commit करने तक लाइव वेबसाइट नहीं बदलेगी।
