# StartPay repository instructions

- Read STARTPAY_AUTOSAVE_POLICY.md before creating or modifying any StartPay form or software that stores customer data. Apply it as the default master-theme policy to future StartPay projects in this repository.
- Follow project-specific AGENTS.md files for branding, versioning and publishing.
- Do not add unsolicited AI-provider branding, attribution or identity URL parameters. Preserve user-supplied URLs, UTM values and necessary parameters.
- Never declare a change LIVE based on a source commit alone: verify the publishing source, deployment result and actual public version. Back up the prior published file and increment changed versions.
